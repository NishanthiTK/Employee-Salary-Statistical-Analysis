# Employee Salary Statistical Analysis

## Project Overview
This project analyzes employee salary data using Python, NumPy, statistical techniques, and data visualization.

## Objectives
- Analyze employee salary distribution.
- Calculate mean, median, mode, variance, and standard deviation.
- Identify salary outliers using the IQR method.
- Analyze salary differences across departments.
- Study the relationship between experience and salary using correlation.
- Compare average salaries across departments using One-Way ANOVA.
- Visualize results using Matplotlib.

## Technologies Used
- Python
- NumPy
- Matplotlib
- CSV
- SciPy (for ANOVA p-value calculation)
- Jupyter Notebook

## Statistical Methods
- Descriptive statistics
- Percentiles and quartiles
- Interquartile Range (IQR)
- Outlier detection
- Skewness
- Pearson correlation
- One-Way ANOVA

## How to Run
1. Download or clone this repository.
2. Install the required libraries:
   `pip install numpy matplotlib scipy jupyter`
3. Open the notebook in Jupyter Notebook.
4. Run the cells in order.

## Dataset
The project uses a CSV dataset containing employee details such as department, age, experience, education, job level, and salary.

## Outcome
The analysis provides insights into salary distribution, departmental salary differences, potential outliers, and the relationship between experience and salary.
